## Rulings (decisions taken without the owner)

- Threat cards now get 10 % of new cards at every level (spec mix).
- `backfillPlayoutCards(db)` takes no engine pool: own-game cards need none.
- Engine failure in a step answers 503 "Engine not available.", like `/check`.
- A move that ends the game is judged like any other move (a stalemate when
  winning is a blunder and rewinds).
- Play-it-out answers are never "failed": all four ratings stay available.
- Each repertoire end is checked with Stockfish once; the checked list is the
  setting `playout_repertoire_checked`. Cost: an end is never re-checked.
- The play-it-out jobs start from `startBackgroundJobs(db, reps)`, which
  `main.ts` now calls after the repertoires load.
- A removed repertoire line keeps its old card until suspended.
